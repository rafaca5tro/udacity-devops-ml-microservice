> **Udacity Cloud DevOps Engineer Nanodegree** -- ML Microservice

Containerized Flask ML microservice with Docker and Kubernetes deployment, serving housing price predictions via scikit-learn.

---

## Key Concepts

- Docker containerization of ML models
- Kubernetes pod deployment
- Flask REST API for predictions
- CircleCI CI/CD pipeline
- Container orchestration

---

## Getting Started

```bash
python app.py              # Run locally
./run_docker.sh            # Run in Docker
./run_kubernetes.sh        # Deploy to K8s
```
